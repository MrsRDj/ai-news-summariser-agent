SUMMARY: Google Cloud AI Research, in collaboration with Washington University in St. Louis and UNC Chapel Hill, has launched EnvHarness, an innovative layer that adapts static agent benchmarks to enhance policy training. By creating wrappers around existing environments through the standard reset()/step() interface, EnvHarness enables dynamic task adjustments, leading to improved performance across benchmarks with significant reductions in execution steps.

KEY POINTS:
- EnvHarness is an Apache-2.0 layer designed to convert static agent environments into adaptive training settings.
- It utilizes a standard interface while preserving existing tasks and human-built verifiers.
- The EnvRigger, an LLM designer, automatically generates wrappers based on flaws detected in agent rollouts.
- Across five benchmarks, the implementation has shown improvements of up to 9.0 points on held-out tasks with 9.8% fewer execution steps.
